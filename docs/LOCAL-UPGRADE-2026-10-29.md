# Wordbook Fresh 本地升级交付与测试报告

日期：2026-10-29（用户时区）。仅修改现有 wordbook-fresh，未修改 TapBook / wordbook-v4。**没有推送或部署本次升级；线上仍为此前移除跨App收藏的版本。**

## 1. 检查结果与例句缺失原因

- 现有词典是公开 ECDICT 静态分片（MIT），401,998条；字段为 word / ipa / translation / definition / exchange / lemma 等。原始导出不包含通用的双语 examples 字段，无法靠调整字段名获得例句。
- 旧展示仅从 supplement.js 的五个词读取10条预制例句；查询与存储没有外部例句补充流程。不是网络请求漏保存例句导致。
- 旧收藏状态直接为 learning，立即计入到期队列；“已经记住”直接永久退出，无法区分新词与真正掌握。
- 旧恢复会把 card 清为 null，可能丢掉随卡片保存的用户内容。本次改为保留卡片及扩展字段，重复记录仍以当前设备数据优先。

## 2. 已实现的增量功能

- 首页总单词、待复习、已掌握都可点击筛选列表；列表搜索、完整详情继续复用同一词典卡。
- 新词先为 new / 待学习，不算到期复习。新学与复习分开；每日5/10/15/25可选，设置持久化，默认10；当日已经接触过的新词计入额度。
- 问题面只显示英文与发音，提供“不认识、认识、不再出现”。前两者保存判断后展示答案，再点下一个；不再出现直接掌握并推进。
- 认识累计当前单词轮次连续次数，不认识清零。连续2次只通过本轮，仍安排未来复习，永不因此自动永久掌握。
- 至少穿插2个不同词再重复，最多4次判断。词数不足时延后，保留该词未完成的轮次ID、连续次数与尝试次数；到期后续上该词的同一轮次，不能通过刷新立即刷出第二次认识。达到上限的词下一次再开始新的单词轮次。
- 最近学习、最近复习、下次日期、判断历史、掌握时间与来源都保留；详情可看最近20条，JSON保留全部。已掌握可搜索、查看和重新学习，重学保留历史。
- 判断与当前任务在同一个 IndexedDB 事务中保存，刷新恢复正在显示答案的阶段，不重复计分。继续沿用原数据库与词库。
- 例句优先保留卡片/用户已有数据，再使用本地学习例句；缺少例句/译文时自动尝试 Tatoeba，失败有具体原因、缓存与强制重新补充。
- 19个常见词的35条预制双语学习例句，标记“AI辅助编写，非词典原文”；主要本地例句含词性/含义标签。不是运行时AI生成器。
- 免费补充批次仅处理缺失记录，串行、显示进度，可停止、失败重试；保护手动内容、去重，删除墓碑防止被自动补回。改写英文后旧句也不会重新出现。
- 每条例句可独立朗读英文，复用系统英语语音；无语音或朗读失败有提示。单词朗读保留。
- 按本次完整指令恢复可选的跨App接收及折叠教程；支持正式子路径、编码、多词去重、人工确认。教程是手动配置配方，不是已真机验证的iCloud安装文件。
- 收藏后的词典补全在后台串行进行，不阻止开始学习/浏览；可暂停，未完成可在详情或批量补充中继续。

## 3. 实际例句来源、许可、联网与费用

| 来源                    | 用途                                         | 费用 / Key                              | 归属与限制                                                                                                         |
| ----------------------- | -------------------------------------------- | --------------------------------------- | ------------------------------------------------------------------------------------------------------------------ |
| ECDICT 静态数据         | 中文释义、旧式音标、词性、原始英文解释、词形 | 随站部署，无Key                         | MIT；保留原始SOURCE与LICENSE；它不提供本次通用双语例句                                                             |
| 项目预制学习例句        | 常见词/义项的35组中英句子                    | 本地，无联网、无Key                     | AI辅助编写，明确非权威词典原文；本地学习句以CC0-1.0提供                                                            |
| Tatoeba 官方稳定 v1 API | 缺失时查询英文及直接关联的普通话译文         | 本次未使用Key、未调用收费服务；需要联网 | 仅接受字段标明 CC BY 2.0 FR / CC0 1.0、有作者、未标记不合格、直接关联的译文；保留英/中两条来源链接、作者、各自许可 |
| 设备 speechSynthesis    | 单词与英文例句朗读                           | 无付费API                               | 依赖设备已提供的英语语音；未使用Tatoeba音频，避免把句子许可套用于录音                                              |

官方文档：[Tatoeba API](https://api.tatoeba.org/)、[官方OpenAPI](https://api.tatoeba.org/openapi.json)、[语料使用与许可](https://en.wiki.tatoeba.org/articles/show/using-the-tatoeba-corpus)、[ECDICT](https://github.com/skywind3000/ECDICT)。

实际参数：lang=eng，sort=relevance，trans:lang=cmn，trans:is_direct=yes，过滤未认可/无主句，限定3–20词，每次最多20条返回。只用完整英文词边界和ECDICT明确词形/原形关系匹配，不使用任意后缀猜测。coven不等于covenant，right不匹配bright。

本次查到的官方文档未提供可承诺的固定免费配额/SLA；不能假定无限请求。客户端批次间隔约1.1秒，成功7天缓存、失败1小时退避，12秒请求超时，处理HTTP429；强制重试仅针对失败/不完整项。没有秘密密钥写入前端，也没有假装存在远程AI生成服务。

**真实浏览器联网验证**：tomorrow 自动补到4组直接关联双语句，均保留原始来源。人工检查的如 “Call me tomorrow.” / “明天打电话给我。” 来自英文句1493515（Keder）与译句1738150（sadhen），均CC BY 2.0 FR。[英文来源](https://tatoeba.org/en/sentences/show/1493515) / [译文来源](https://tatoeba.org/en/sentences/show/1738150)。

**准确性边界**：Tatoeba直接关联证明语料中的翻译关系，不等于已由本程序独立完成语义审校；界面明确标为社区语料、具体词义需核对，绝不仅凭中文字符认定正确。不把未分类语料强行分配给某个词义。不能保证所有常见词的每个义项都已有1–2句；缺失/旧句缺译文继续显示缺失。没有用不相关例句填满卡片。维基词典未用于本次运行时补充，无需额外混入其许可。

## 4. 临时复习参数，供以后确认

集中在 src/learning.js 的 REVIEW_CONFIG：

| 参数                | 当前默认           | 说明                                       |
| ------------------- | ------------------ | ------------------------------------------ |
| 成功间隔            | 1、3、7、14、30天  | 后续成功停留30天，不永久掌握               |
| 失败/无法穿插的延后 | 10分钟             | 临时值，不是声称科学确定的统一艾宾浩斯公式 |
| 每词当前轮次上限    | 4次                | 延后恢复同一单词轮次时继续计数             |
| 再次判断前穿插      | 2个不同单词        | 词太少时延后，不立即重复                   |
| 自动永久掌握        | 关闭（null）       | 当前仅用户“不再出现”永久掌握               |
| 每日新词默认        | 10，可选5/10/15/25 | 用户可直接调整                             |

历史兼容的 grade 函数仍保留供旧接口/回归测试使用，但新版界面不调用它；新版行为只由 learning.js 控制。需要之后确认的是成功间隔、失败延后、上限、穿插要求，以及是否启用任何自动掌握规则；不影响当前本地试用。
