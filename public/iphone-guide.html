一次设置，随处收藏生词

使用 iPhone 的系统分享菜单和「快捷指令」。网页无法自行读取其他App选中的文字，必须由你分享或粘贴。

1. 正式网址

2. 建立「收藏到英语单词本」

  1. 打开 iPhone「快捷指令」App，点右上角 ＋，命名为收藏到英语单词本。
  2. 打开快捷指令的详情，启用在共享表单中显示。不同iOS版本入口可能是顶部名称下拉菜单、ⓘ或设置按钮。
  3. 将接收类型设为文本、多信息文本、URL。如果分享菜单不出现，可再允许Safari网页；但Safari有时只传网址或标题，不一定传选中文字。
  4. 添加获取输入中的文本（或“从输入中获取文本”），输入选快捷指令输入。
  5. 添加合并文本，分隔符选新行，输入选上一步文本。这一步支持一次分享多个单词。
  6. 添加如果，条件为“合并后的文本没有任何值”。在这个分支加入显示提醒：“请选中英文后分享，或复制后到单词本粘贴。”再加入停止此快捷指令（部分版本叫“停止并输出”），结束如果。
  7. 添加URL编码，选择编码，输入选合并后的文本。只编码文字，不要编码整个网址。
  8. 添加文本，粘贴上方正式收藏前缀。在等号后插入上一步URL编码的结果变量。前缀与变量之间不要加空格或换行。
  9. 添加URL操作，输入为上一步完整文本；再添加打开URL操作，输入选上一步URL。保存。

操作顺序：获取输入中的文本 → 合并文本（新行）→ 空值判断 → URL编码（编码）→ 文本（正式前缀＋编码变量）→ URL → 打开URL。本次提供可手动配置的配方，没有声称提供已签名、已真机安装的快捷指令文件。

3. 在Safari和其他App中使用

  1. 在英文网页长按选中 study，或一段含多个单词的文字。
  2. 在选中文字的浮动菜单中点分享，选择收藏到英语单词本。菜单没有显示分享时，可点箭头或“更多”。
  3. 单词本会打开收藏确认页面。核对拼写、编辑、取消选择或删除，再点收藏选中的单词。确认前不写入词库。
  4. 重复词不会重复建档，已掌握状态和原复习时间保留。短语当前按独立单词拆分，程序不假装支持独立短语卡片。

4. 只收到整页网址，或App不支持分享文字

Safari底部分享按钮可能分享整个网页，而不是选中文字。只收到网址时，网站提示无可收藏文字，不把域名和网址路径作为单词。

  • 能复制：复制 → 在Safari打开正式单词本 → 收藏单词 → 粘贴 → 检查 → 确认。
  • 不能选字或复制：截图 → 收藏单词 → 照片/截图 → OCR识别 → 人工核对 → 确认。
  • 快捷指令未出现在分享菜单：检查“在共享表单中显示”和输入类型；仍没有时用复制或截图。不同App可能不提供文字输入。
  • 不同iOS版本操作名称有差异：搜索“文本”“URL编码”“打开URL”等关键词；也可从快捷指令App手动运行，但无输入时按提示改用粘贴。

5. 数据与离线

建议统一在Safari中使用同一个正式网址。Safari与主屏幕独立PWA的数据不能假定共享；原来在电脑本地或其他域名保存的词库，需要在旧入口导出JSON，再在正式网址恢复。不要清除旧入口的数据。

分享文字通过URL片段传递，不随页面HTTP请求发送；浏览器历史/剪贴板仍可能暂时包含文字。长文章或敏感文字请直接粘贴，不放在链接里。完全离线且尚未打开过正式网站时，快捷指令无法加载网站，请先复制文字留存。已缓存资料可离线使用，未加载过的词典分片或OCR模型可能需要联网。

6. 首次真机验收

  • Safari选中 study → 分享 → 确认收藏。
  • 分享 study book study → 仅新增两个独立词。
  • 再次分享已掌握词 → 保留原状态和复习时间。
  • 分享整页网址 → 不自动建词。
  • 在一个支持分享文字的其他App中重复测试；不支持则验证复制/截图备用路径。
  • 刷新正式网站 → 已确认的收藏仍存在。

网站接收端可自动测试；系统分享菜单、快捷指令操作名称、相机/相册权限和真机OCR仍需在你的iPhone上验证，不宣称100%兼容。
